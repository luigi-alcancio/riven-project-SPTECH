# Riven Academy

Projeto de desenvolvimento web dedicado à Riven, campeã de League of Legends, criado como projeto pessoal e acadêmico na SPTech.

A proposta é desenvolver uma plataforma interativa com guias de matchups, quizzes, dashboards e funcionalidades de autenticação, utilizando o projeto como ambiente prático para aprender e aprofundar conhecimentos em desenvolvimento front-end, back-end, APIs e bancos de dados.

## Objetivos

- Desenvolver uma aplicação web completa do front-end ao back-end.
- Praticar HTML, CSS e JavaScript na construção de interfaces interativas.
- Utilizar APIs utilizando Node.js.
- Implementar funcionalidades de cadastro, login e autenticação de usuários.
- Integrar e manipular dados armazenados em um banco de dados.
- Criar dashboards com visualizações gráficas utilizando Chart.js.
- Desenvolver quizzes e recursos interativos para aprendizagem.
- Aplicar na prática os conhecimentos adquiridos durante a formação na SPTech.

## Funcionalidades planejadas

- **Matchups:** guias e análises de confrontos da Riven contra outras campeãs.
- **Quizzes:** testes interativos para revisar conhecimentos sobre a campeã e o jogo.
- **Dashboards:** gráficos e indicadores para visualizar dados da aplicação.
- **Autenticação:** telas de cadastro, login e gerenciamento de usuários.
- **Banco de dados:** armazenamento e consulta das informações da plataforma.
- **Interface interativa:** navegação, componentes visuais e recursos desenvolvidos com JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- APIs REST
- Banco de dados relacional
- Chart.js

## Propósito educacional

Este projeto tem como objetivo unir um interesse pessoal por League of Legends ao aprendizado de desenvolvimento de software, permitindo explorar conceitos de front-end, back-end, integração entre sistemas, persistência de dados e visualização de informações.

O projeto será desenvolvido de forma incremental, com novas funcionalidades e melhorias implementadas conforme a evolução dos estudos.
